# Imoplace 3.4.2 — alinhamento das opções do formulário

A qualificação usa duas colunas no desktop e uma coluna em telas de até 480 px. Os seletores têm 16 px e os cartões mantêm o alinhamento quando um texto ocupa mais de uma linha. Os botões Voltar e Concluir envio têm a mesma largura.

As fichas publicadas e as novas páginas usam a mesma folha de estilos e o mesmo módulo de formulário. As quatro perguntas, a identificação do imóvel e o contrato com a API seguem a configuração descrita na documentação da 3.4.1.

A publicação sai pelo workflow existente do GitHub Pages. CORE Apps Script 3.4.0 e Monitor GS 1.0 continuam em uso.
